# Black Tower Consulting Site

Landing pública de Black Tower Consulting: consultora de automatización IA, software interno y MVPs operativos para pymes industriales/logísticas.

## Alcance V1

- Sitio estático React/Vite/TypeScript.
- Sin backend, base de datos ni formularios propios.
- CTA por `mailto:` para diagnóstico inicial.
- Despliegue recomendado: Coolify + Dockerfile + Nginx.

## Comandos

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run preview
```

## Despliegue

- Build pack: Dockerfile.
- Puerto expuesto: `80`.
- Dominio: `https://btc.etharlia.com`.

## Límites de copy

La landing promete un **prototipo funcional de un proceso acotado en 7 días**, no una implantación completa, ROI garantizado ni automatización sin supervisión humana.
